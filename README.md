# ACE Programming Tasks 2026

A collection of beginner-to-moderate level Python programs built as part of my ACE programming practice tasks. Each program focuses on core programming concepts — loops, functions, file handling, and basic algorithms — implemented from scratch without relying on built-in shortcuts.

## 📂 Tasks

### 1. Password Strength Checker
Checks a user's password against 6 strength criteria (length, uppercase, lowercase, digit, special character, and non-consecutive digit rule), then displays a pass/fail breakdown along with an overall strength score (Weak / Medium / Strong / Extreme).

### 2. Student Result Analyzer
A menu-driven CSV-based program to create and manage student result reports — add student entries, calculate grades, view class summary/analysis (average, highest/lowest scorer, pass percentage, grade-wise distribution), and display all entries.

### 3. The Missing Number (DSA)
Finds the missing number from a sequence of 1 to n using two different algorithmic approaches:
- **Mathematical Approach** — using the sum formula (AP series)
- **DSA Approach** — sorting the list and detecting the gap in sequence

Includes complexity comparison between both approaches.
